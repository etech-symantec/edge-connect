ProxySG Local Operations

Edge Connector

SSH 및 Management HTTPS를 이용해 ProxySG에 직접 연결하고, 장비 설정부터 Local Admin 관리, Trace 정책 테스트, LIVE 조회와 분석까지 하나의 로컬 도구에서 수행합니다.

사용 절차 장비 설정 후 Local Admin, Trace 정책, MIB/SNMP 작업으로 분기됩니다.
1

장비 설정

SSH · HTTPS

ProxySG의 관리 IP, SSH 접속 정보, Management HTTPS 정보를 등록합니다. 자주 사용하는 장비는 프로필로 저장해 이후 Local Admin 관리나 Trace 정책 작업에서 다시 입력하지 않고 사용할 수 있습니다.

장비 연결 정보 관리 SSH / Management HTTPS 분리 설정 장비 프로필 재사용
2A

Local Admin 설정 / 관리

ADMIN

장비 연결 후 Local Admin 작업이 필요한 경우 이 경로로 분기합니다. ProxySG의 Local Admin 계정을 확인하고 추가·변경 등 운영에 필요한 계정 관리 작업을 수행하며, Trace 정책 작업과는 독립적으로 사용할 수 있습니다.

Local Admin 계정 확인 운영 계정 추가 / 변경 Trace 작업과 독립적으로 수행
2B

Trace 정책 설정

LOCAL POLICY

장비 연결 후 Trace 테스트가 필요한 경우 이 경로로 분기합니다. Source, Destination, 인증 사용자, HTTP Method/Service, Logging 이름과 Trace 파일명을 조건으로 Trace CPL을 생성해 Local Policy에 적용하고, 테스트 후에는 Edge Connector가 추가한 동일 정책만 안전하게 제거합니다.

현재 Local Policy 조회 Trace CPL 자동 생성 / 미리보기 적용한 Trace 정책만 정확히 제거
3

LIVE Trace / Access Log 조회

LIVE

Management HTTPS를 통해 생성된 Trace 파일과 Access Log를 실시간으로 조회합니다. 최근 세션 중심으로 확인하거나 전체 내용을 펼쳐 보고, 로그 조건에 따라 필요한 트랜잭션을 빠르게 좁힐 수 있습니다.

LIVE Trace 갱신 Access Log Tail 최근 세션 / 전체 세션 전환
4

세션 분석

ANALYSIS

Trace와 Access Log에서 Verdict, Protocol, Response Code, Transaction Timing, Miss/N/A/Late 등의 정보를 기준으로 문제 세션을 분석합니다. 정책 결과와 응답 지연을 함께 확인해 장애 원인 파악 시간을 줄입니다.

Verdict / Protocol / Response Code Transaction Timing 확인 Miss / N/A / Late 필터
2C

MIB / SNMP 조회

MIB · SNMP

장비 연결 후 MIB 정보를 확인해야 하는 경우 이 경로로 분기합니다. ProxySG 관련 MIB와 OID 정보를 조회하고 필요한 SNMP 항목을 빠르게 찾아 모니터링 구성이나 장애 분석에 활용할 수 있습니다.

MIB / OID 검색 SNMP 항목 확인 모니터링 구성 참고
2D

Sysinfo 확인

SYSINFO

장비 연결 후 ProxySG Sysinfo를 직접 확인하는 작업입니다. 장비의 상태와 주요 설정 정보를 한 곳에서 조회해 현재 구성이나 장애 분석에 필요한 정보를 빠르게 확인할 수 있습니다.

Sysinfo 조회 장비 상태 확인 주요 설정 정보 점검
2E

Exception Page 편집

EXCEPTION PAGE

ProxySG의 Exception Page를 별도 작업으로 조회하고 편집하는 기능입니다. 현재 내용을 확인한 뒤 필요한 문구나 페이지 내용을 수정해 Exception Page 관리 작업을 Edge Connector에서 직접 수행할 수 있습니다.

Exception Page 조회 페이지 내용 편집 운영 문구 수정
