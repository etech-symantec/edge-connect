ProxySG Edge Connector

Chrome 확장프로그램 설치 가이드

Edge Connector Chrome 확장프로그램과 Native Host를 설치하고, Repo의 최신 Edge Connector 버전을 자동 확인해 실행하는 절차입니다.

🧩 최신 설치 CMD 다운로드 ← Edge Connector 페이지로 돌아가기

설치 순서

1
설치 CMD 다운로드

위 버튼 또는 Edge Connector 메인 페이지의 Chrome 확장프로그램 설치 버튼을 눌러 Install_Edge_Connector_Chrome_Native.cmd를 다운로드합니다.

2
다운로드한 CMD 실행

CMD를 실행하면 Repo의 extension/native-version.json을 확인해 현재 최신 Chrome Native 패키지를 자동으로 다운로드하고 SHA-256 검증 후 설치합니다.

3
UAC가 나오면 허용

Edge Connector 본체 업데이트나 Native Host 설치에 관리자 권한이 필요한 경우 Windows UAC가 표시될 수 있습니다. 예를 선택합니다.

4
Chrome 확장프로그램 확인

Chrome에서 chrome://extensions를 열어 ProxySG Edge Connector가 설치 및 활성화되어 있는지 확인합니다. 기존 버전이 보이면 새로고침 버튼을 한 번 눌러주세요.

5
확장 아이콘 실행

확장 아이콘을 클릭하면 Repo의 Edge Connector 최신 버전을 확인합니다. 로컬 버전이 낮으면 최신 버전으로 업데이트하고, 최신 상태이면 바로 Edge Connector를 실행합니다.

6
127.0.0.1 연결 확인

Edge Connector 실행 후 실제 로컬 LISTEN 포트를 확인해 127.0.0.1 주소로 자동 연결되면 설치가 완료된 것입니다.

최신 버전 번호는 확장프로그램에 하드코딩되지 않습니다. Repo의 버전 정보가 1.1.13, 1.1.14 등으로 변경되면 설치 CMD가 자동으로 최신 패키지를 선택합니다.

문제가 있을 때

A
확장프로그램이 예전 버전으로 보일 때

chrome://extensions에서 ProxySG Edge Connector의 새로고침 버튼을 누른 뒤 다시 실행합니다.

B
설치 버전과 Repo 버전이 다를 때

확장 아이콘을 다시 실행하면 Repo 최신 버전을 다시 확인합니다. 업데이트가 필요한 경우 UAC를 허용하고 완료 후 다시 실행합니다.

C
연결 실패가 계속될 때

Edge Connector 페이지의 최신 버전 확인을 먼저 확인하고, 필요하면 Edge Connector 본체와 Chrome 확장프로그램 설치 CMD를 각각 다시 실행합니다.

설치 버튼은 브라우저 보안 정책 때문에 CMD를 자동 실행하지는 못합니다. 다운로드 후 사용자가 한 번 실행해야 합니다.
